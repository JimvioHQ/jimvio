## What this is

The **Product Operating System (JPOS)** governs every product decision. This **Operating Model** provides tactical detail — feature tiers, RACI, review gates, and release mechanics — referenced by JPOS Part 2 and Part 3.

| Document | Role |
|----------|------|
| **[JPOS](../product-operating-system/)** | *Strategic* — philosophy, lifecycle, governance, quality, decision matrix, portfolio, KPIs |
| **Operating Model (this)** | *Tactical* — tiers, RACI, gates, release phases, shortcuts |

## Quick reference: feature tiers

| Tier | Examples | Approval level |
|------|----------|----------------|
| **T1** | Payments, auth, checkout | Founder + Security + CTO |
| **T2** | Orders, wallet, marketplace core | CTO + Product + Security |
| **T3** | UGC, affiliate, communities, AI | Product + Eng + Design |
| **T4** | UI polish, analytics widgets | Eng lead + Design |
| **T5** | Experiments, prototypes | Product + Eng (lightweight) |
