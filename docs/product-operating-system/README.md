## What JPOS is

The **Product Operating System** governs how ideas become shipped products while maintaining world-class quality. It is the strategic layer above tactical execution.

| Document | Role |
|----------|------|
| **[JPOS (this)](./JIMVIO-PRODUCT-OPERATING-SYSTEM-v1.0.md)** | Philosophy, lifecycle, governance, quality, decisions, portfolio, KPIs |
| [Product Bible](../product-bible/) | Permanent strategic truth |
| [Operating Model](../operating-model/) | Tactical lifecycle detail — tiers, RACI, release mechanics |
| [PRD Standard](../prd/) | Feature intake |
| [Platform Standards](../platform-standards/) | Implementation quality |
